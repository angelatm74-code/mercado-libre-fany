# Mis Recomendaciones - Mercado Libre Fany

Página web de enlaces de afiliados de Mercado Libre con buscador en tiempo real.

## 🌐 Acceder a la página

Abre el archivo `index.html` en tu navegador o accede a través de GitHub Pages.

## ✨ Características

- 🔍 Buscador en tiempo real
- 🎨 Diseño moderno con fondo azul
- ➕ Agregar productos fácilmente
- 💾 Los datos se guardan automáticamente
- 📱 Responsive (funciona en móvil y computadora)

## 📝 Cómo usar

1. **Agregar un producto:**
   - Escribe el nombre
   - Pega la URL de la imagen
   - Pega el link de Mercado Libre
   - Haz clic en "Agregar Producto"

2. **Buscar productos:**
   - Usa la barra de búsqueda
   - Filtra en tiempo real

3. **Eliminar un producto:**
   - Haz clic en el botón "Eliminar" en la tarjeta

¡Listo! 🎉
